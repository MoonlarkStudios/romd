# Collections

Collections are ordered lists you can reuse across audience libraries. Open
**Collections** in the admin app to create one or edit an existing collection.

- **Build** lets you search beside the ordered collection, add up to 24 games
  at a time, change order, and edit per-game notes. Search starts with local
  games. Turn off **Local files only** to search the full catalog. Use **Add to
  libraries** to choose several destinations in one step. Smaller screens offer
  a **Find games** and **Collection** toggle. Both lists show the title's selected
  cover. Edit details and artwork from the workspace header.
- **Audiences** lets you attach the collection to libraries and inspect their visible / total
  game counts and featured placement. Unlink an audience using the same unlink
  icon as the library view; other attachments retain their order and featured
  settings. Library links open attachment management.
- **Preview** shows owned games and their selected covers for an attached
  audience. Investigate a game using the library evaluator for rating and ownership
  explanations. The preview uses the published audience while changes wait for
  publication. A library that has never been published or has an invalid policy
  cannot be previewed.

Edits save immediately and affect every attached library. Batch additions are
individual requests, not an atomic operation: successful additions remain saved,
while failed and unattempted games remain selected. System collections stay
read-only. Existing role permissions still apply; audience management and preview
require Admin access.

See [audience libraries](library-audience-workspace.md) for assignment and
publication, or [Your first library](first-library.md) for the complete setup.
