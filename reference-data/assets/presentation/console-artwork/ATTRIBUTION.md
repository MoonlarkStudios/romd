# Console and controller artwork

The NES, Genesis, Super Nintendo, PlayStation, and Nintendo 64 illustrations
were generated with OpenAI image generation and reviewed for hardware silhouette
and details. Each pair uses a low three-quarter view of the console and a
controller close-up in a screen-print style. Shipped images use a 4:3 aspect
ratio. System logos are supplied separately in the [platform logo collection](../platforms/ATTRIBUTION.md).
